# Web portfolio

This solo project is a portfolio presented as a collection of articles.
It is structured across several pages.
The homepage introduces the site and provides quick access to featured projects.
Clicking on an article opens a dedicated project page.
Each project page includes a detailed presentation and, at the bottom, a link to the latest posts.
The “About Me” page offers a personal introduction.

## Technical requirements

- [x] Follow a Figma design
- [x] Use mobile first 💜
- [x] Responsive design (media queries, relatives units, viewport meta tag) 🚀
- [x] Deploy on Github and Netlify
